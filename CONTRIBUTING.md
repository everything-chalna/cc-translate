# Contributing

Keep the app focused on translating selected text through ChatGPT on macOS.

Run `npm test`, `npm run build:shortcut`, and `native/selection-shortcut --self-test` before submitting changes. Run `npm run dist` to verify packaging. Manually check selection capture, Accessibility onboarding, streaming, Copy, Close, and prompt saving when changing those flows.

Never commit credentials, local configuration, or copied user text. Preserve the MIT license and upstream attribution.
